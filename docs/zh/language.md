# 语言参考（速查）

面向使用者的速查表。完整规范：[RFC 0000](https://github.com/OrbitZore/pcl/blob/main/rfc/rfc-0000-language.zh.md)。

## 构造

| 构造 | 语法 | 一句话语义 |
|---|---|---|
| 发起型插值 | `${STMTS}` | 真 Python 语句；表达式值插入输出；行号 1:1 |
| 合并型插值 | `$(STMTS)` | 同上但织入合并段；适合同行拼值 |
| 指令 | `${:动词 …}` | 控制流/上下文/pass |
| 注释 | `${:# …}` / `${# …}` | 至行尾丢弃；**须独占一行** |
| 注记 | `$(# … #)` | 渲染后经 note 下发——不进 LLM 上下文 |
| 上下文注入 | `$(@ … @)` | 独立用户消息进会话——不触发推理 |
| 转义 | `$$` | 字面 `$` |

**扩展定界符**：`$(end# 内容含 #) 字面 #end)`——开头 `<delim>#`、
结尾 `#<delim>)` 严格对称；闭合不存在则回落为普通 `$()`。

## 闭合规则

- `${…}` 按 `}`、`$(…)` 按 `)`——括号配平、字符串/注释感知
- 三引号字符串内可跨行；指令一律单行

## 行为规则

- **独行消除**：行内全部构造无输出 → 整行移除（指令、纯语句、注释、
  `$(@ @)` 行）；注记行**不**消除；空行保留
- **`text()` 输出**：`str` 原样；`None`→`null`；`bool`→`true/false`；
  dict/list/tuple→紧凑 JSON；其他 `str(v)`
- **保留名**（绑定即 C300）：`emit text submit save load new_ctx
  push_sink pop_sink note context`；函数名 `main prompt reply`；
  `__pcl_` 前缀

## pass

```text
${:pass :read 快照名 :write 写回名}
```

- prompt 体至下一个指令；自动提交（trim）
- `:write` 自动包装：唯一授权名 + agent 全平铺 → 嵌套
- 空 prompt 跳过；空回复 A504；越权写 R406；写回深度 ≤32

## 错误码速查

| 类 | 典型码 | 退出码 | 含义 |
|---|---|---|---|
| L | L100–L102 | 1 | 词法 |
| P | P200–P203 | 1 | 解析 |
| C | C300/C305/C310 | 1 | 编译约束 |
| R | R400/R406/R430 | 2 | 运行期 |
| A | A500–A523 | 3 | 桥接 |
| SIGINT | R409 | 130 | 中断 |

常见：**C305** 注释没独占一行；**C300** 绑定了保留名；**R406**
agent 写了未授权名；**A504** agent 无有效回复；**R430** `:load`
的会话文件不存在。
